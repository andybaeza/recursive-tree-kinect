# Interactive Recursive Tree with Kinect 🌳

A real-time generative visualization in which a **recursive tree grows and changes with your hand movements**. A Kinect sensor tracks the position of the user's hands, and the tree's angle and color respond instantly. Built with **Processing (Java)** and **SimpleOpenNI**.

Shown to the public at **FILEY** (*Feria Internacional de la Lectura Yucatán, 2025*), a cultural event with 240,000+ attendees, and tested by 50+ users.



<br>

---

## Concept

The project explores the link between nature and human motion through code: every gesture becomes a parameter that shapes a digital tree, turning interaction into organic growth.

### How it Works
1. The Kinect sensor detects the user's hand positions in 3D space.
2. SimpleOpenNI passes that data to the Processing sketch.
3. A recursive algorithm draws the tree, where each branch spawns smaller branches:
   * Angle changes with the horizontal position of the hands.
   * Color changes with the vertical position of the hands.
4. The tree is redrawn every frame, so it mirrors the user's gestures in real time.

## Technologies

- **Processing with Java**
- **SimpleOpenNI library** for Kinect integration
- **Microsoft Kinect v1** sensor
- Recursive algorithms for tree generation
